# 06. 평가 기준

| 항목 | 비율 |
|---|---:|
| 출석 | 10% |
| 각 주차별 과제 진행 | 40% |
| **최종결과물** (빌드 파일 및 영상) | **40%** |
| 최종 발표 및 PPT | 10% |
| **합계** | **100%** |

## 최종결과물 40% 세부

| 항목 | 비율 |
|---|---:|
| 캐릭터 디자인 완성도 | 10% |
| 애니메이션 완성도 | 10% |
| 배경/스테이지 그래픽 | 10% |
| Unity 적용 완성도 | 5% |
| 전체 분위기와 통일성 | 5% |

프로그래밍 능력보다 **그래픽 리소스가 게임 안에서 얼마나 잘 작동하는지**를 중심으로 평가합니다.

## 알아두면 좋은 것

- **주차별 과제(40%)가 최종결과물(40%)과 같은 비중입니다.** 마지막에 몰아서 만드는 것보다 매주 꾸준히 내는 것이 점수에 유리하고, 실제로 완성도도 그쪽이 높습니다.
- **"Unity 적용 완성도"** 는 그림 실력이 아니라 **넣은 리소스가 게임에서 제대로 작동하는가**를 봅니다. 규격에 맞는 파일명·크기로 넣었는지, 애니메이션 판정 프레임이 맞는지, 빌드에서도 정상인지 등입니다. 그림을 아무리 잘 그려도 게임에 반영이 안 되어 있으면 점수가 되지 않습니다.
- **"전체 분위기와 통일성"** 은 캐릭터·배경·UI·컷신이 **한 게임처럼 보이는가**입니다. 각 요소를 따로 잘 그려도 화풍이 제각각이면 여기서 깎입니다. 그래서 2주차 컨셉 구상을 처음에 잡아두는 것이 중요합니다.

제출 항목과 방법은 [05_제출_가이드](05_제출_가이드.md)를 확인하세요.
