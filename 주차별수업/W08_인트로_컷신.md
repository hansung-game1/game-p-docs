# 8주차 - 인트로 컷신 (러프 단계)

**이번 주 목표**: 게임의 이야기를 여는 장면을 만든다.

---

## 1. 인트로 컷신의 특징

### 게임 흐름에서의 위치

```
타이틀 화면 → [ 인트로 컷신 ] → 스테이지(전투) → 클리어 → 엔딩 컷신 → 타이틀
```

타이틀에서 **"시작하기"** 를 누르면 바로 이 화면으로 넘어옵니다. 컷신이 끝나면 자동으로 스테이지가 시작됩니다.

### 어떤 형태인가 - 슬라이드 방식

```
┌────────────────────────────────────────────┐
│                                            │
│                                            │
│          cutscene01.png                    │  ← 1920x1080 전체 화면 그림
│          (한 장면)                          │
│                                            │
│                                            │
│                                            │
│   [◀ 이전]              [다음 ▶]  [건너뛰기] │  ← 버튼 3종
└────────────────────────────────────────────┘
```

- **한 장씩 넘겨보는 만화/그림책 방식**입니다. 애니메이션이 아닙니다
- 장면 수는 **자유롭게 늘리거나 줄일 수 있습니다**
- 플레이어는 **다음 / 이전 / 건너뛰기** 버튼으로 조작합니다

### 이야기를 어떻게 구성하나

여러분이 만드는 게임은 **스테이지 1개, 약 3분** 분량입니다. 인트로는 그 앞에 붙는 짧은 도입부이므로 **3~6장 정도**가 적당합니다. 너무 길면 플레이어가 건너뛰기를 누릅니다.

**최소한 이 세 가지만 전달되면 충분합니다:**

1. **여기가 어디인가** (세계관/상황)
2. **주인공은 누구인가**
3. **왜 싸우러 가는가** (목적/동기)

> **구성 예시 (4장)**
> 1. 평화로운 마을/세계의 모습
> 2. 사건 발생 - 몬스터의 습격, 무언가를 빼앗김
> 3. 주인공의 등장 - 결심하는 순간
> 4. 출발 - 스테이지로 이어지는 장면

> **연출 요령**: 4장이라면 **와이드샷 → 미디엄 → 클로즈업 → 와이드샷** 처럼 화면 크기를 바꿔가며 리듬을 만드세요. 같은 거리의 그림만 이어지면 지루해집니다.

## 2. 리소스 제작 규격

폴더: `Assets/_Project/04_Art/StudentReplace/Story/IntroCutscene/`

### 장면 이미지

```
cutscene01.png, cutscene02.png, cutscene03.png ...
```

| 항목 | 규격 |
|---|---|
| 파일 형식 | **PNG** |
| 크기 | **1920 x 1080px** |
| 알파 채널 | **필요 없음** (화면을 꽉 채우는 그림) |
| 번호 | **두 자리** (01, 02 ... 09, 10, 11) |
| 장 수 | **자유** |

> **파일명이 정확히 `cutscene`으로 시작해야 인식됩니다.** 앞에 다른 글자를 붙이면(`my_cutscene01.png` 등) **인식이 안 되고 조용히 무시됩니다.** 에러도 안 뜹니다.

### 버튼 3종 - 각 214 x 87px

```
button_next.png    다음
button_prev.png    이전
button_skip.png    건너뛰기
```

| 항목 | 규격 |
|---|---|
| 파일 형식 | PNG, **알파 채널 투명** |
| 크기 | **214 x 87px** |
| 상태 | 1장씩 (hover/click 없음) |

크기가 달라졌으면 `Image` 컴포넌트의 **`Set Native Size`** 로 복구할 수 있습니다.

> 이 버튼들은 **엔딩 컷신에서도 똑같이 쓰입니다**(단, 폴더는 따로입니다 - 9주차에 같은 파일을 복사해 넣으면 됩니다). 두 화면에 다 어울리는 디자인으로 만드세요.

### 정지 이미지 대신 동영상을 쓸 수도 있습니다 (선택)

같은 번호 자리에 **확장자만 `.mp4`** 로 넣으면, 그 장면이 정지 이미지 대신 영상으로 재생됩니다.

```
cutscene01.png   ← 정지 이미지
cutscene02.png   ← 정지 이미지
cutscene03.mp4   ← 이 장면만 영상
cutscene04.png   ← 정지 이미지
```

| 항목 | 권장 규격 |
|---|---|
| 코덱 | **H.264** |
| 해상도 | **1920 x 1080** |

- 이 규격이 아니어도 재생은 되고 화면 비율에 맞춰 자동으로 레터박스 처리됩니다 (화질을 위해 권장)
- **영상 자체에 소리가 없으면 무음으로 재생**됩니다
- 파일명은 마찬가지로 정확히 `cutscene`으로 시작해야 합니다

> 러프 단계에서는 **정지 이미지로 시작하는 것을 권장**합니다. 영상은 여유가 있을 때 12~13주차에 시도해보세요.

### 러프 단계 작업 지침

- 컬러링 없이, 단 **디자인 컨셉과 연출 의도는 담겨 있어야 함**
- **구도와 장면 순서(스토리보드)를 확정하는 것**이 이번 주의 목표입니다
- 러프는 **콘티 수준**이어도 좋습니다 - 대신 각 장면이 무엇을 보여주는지 명확해야 합니다
- 글자(대사/내레이션)를 넣을 거라면 **그림 안에 직접 그려 넣습니다.** Unity가 따로 텍스트를 얹어주지 않습니다
- **AI 사용을 허용합니다** - 구도 시안, 배경 아이디어 등에 활용 가능. 최종적으로는 게임 전체 그림체와 통일되어야 합니다

## 3. Unity에 적용하기

### 순서

**1) 그림을 `Story/IntroCutscene` 폴더에 넣습니다.**

**2) 인트로 컷신 씬을 엽니다.**

```
Assets/_Project/00_Scenes/Flow/IntroCutscene.unity
```

**3) 반영합니다.**

- **파일명/개수를 그대로 두고 덮어쓴 경우**: 자동 반영됩니다
- **장면 수를 바꾼 경우** (늘리거나 줄임):
  ```
  Tools > Class Template > Refresh Intro Cutscene Slides
  ```
  **안전하게 반복 실행 가능**합니다. 컷신 작업에서는 이 명령을 가장 자주 쓰게 됩니다

**4) Ctrl+S로 저장**

> ⚠️ `Tools > Class Template > **Create Intro Cutscene Scene**` 은 실행하지 마세요 (씬을 통째로 새로 만듦).

### BGM 넣기 (선택, 11주차에 본격적으로 다룸)

`Assets/_Project/06_Audio/BGM/IntroCutscene/` 폴더에 음원 파일 **하나**를 넣고:

```
Tools > Class Template > Add Background Music To Intro Cutscene Scene
```

- 파일명은 무관합니다 (mp3/wav/ogg 다 됨). **폴더에 하나만** 넣으세요
- 컷신에 들어가자마자 재생 시작, 장을 넘기거나 되돌아가도 **끊기지 않고 계속 반복**됩니다
- 스테이지로 넘어가면 자연스럽게 멈춥니다

## 4. 확인하고 수정하기

`IntroCutscene` 씬에서 Play.

| 확인 항목 | 방법 |
|---|---|
| 첫 장면이 정상으로 뜨나 | Play 직후 |
| **다음 버튼으로 끝까지 넘어가나** | 계속 눌러보기 |
| **이전 버튼으로 되돌아가나** | |
| 장면 순서가 맞나 | 01 → 02 → 03 순서인지 |
| **마지막 장면 다음에 스테이지로 넘어가나** | 끝까지 넘겨보기 |
| **건너뛰기가 작동하나** | 첫 장면에서 눌러보기 |
| 그림이 잘리거나 늘어나지 않나 | 1920x1080이 아니면 이런 문제가 생깁니다 |
| 글씨가 읽히나 | 실제 화면 크기에서 확인 |

**전체 흐름도 확인하세요**: `Title` 씬에서 Play → 시작하기 → 인트로 → 스테이지 까지 끊기지 않는지.

### 잘 안 될 때

| 증상 | 원인 |
|---|---|
| 장면이 안 바뀜 / 새로 넣은 장면이 안 보임 | **`Refresh Intro Cutscene Slides` 미실행** ← 가장 흔함 |
| 특정 장면만 안 나옴 | 파일명이 `cutscene`으로 시작하지 않거나 번호가 한 자리(`cutscene1.png`) |
| 번호를 건너뛰었더니 이상함 | 01, 02, 03... 연속으로 매기세요 |
| 그림이 늘어나거나 잘림 | 1920x1080이 아님 |
| 버튼이 찌그러짐 | 214x87이 아님 → `Set Native Size` |
| 마지막 장면에서 안 넘어감 | 씬 연결 문제 - 10주차 Build Settings 항목 참고, 또는 질문 |
| mp4를 넣었는데 재생이 안 됨 | 파일명 접두사(`cutscene`) 확인, H.264 코덱인지 확인 |

## 5. GitHub 백업

1. Unity에서 **Ctrl+S**
2. GitHub Desktop → Summary `8주차 - 인트로 컷신 러프` → **Commit to main** → **Push origin**

### 이번 주 특히 주의

- **1920x1080 이미지가 여러 장이라 용량이 큽니다.** Push가 오래 걸려도 중간에 끊지 마세요
- **`.mp4` 동영상을 넣었다면 용량이 훨씬 큽니다.** 한 파일이 100MB를 넘으면 GitHub가 거부합니다 - 영상을 쓸 거라면 **압축해서 100MB 아래로** 맞추세요 (1920x1080 H.264로 몇십 초 분량이면 보통 문제없습니다)

## 과제 (8주차)

### 무엇을 해오나

**인트로 컷신을 러프(스케치) 상태로 제작하고 Unity에 적용하기**

- 완성본이 아닌 **스케치 버전의 러프** 상태
- 스케치지만 **디자인 컨셉은 담겨 있어야 함** (컬러링 X)
- **AI 사용을 허용합니다**
- 권장 분량: **3~6장**

### 제출

네이버 카페 업로드 - 제목 `2D게임제작_08주차_123456홍길동`

- [ ] **인트로 컷신 리소스** (장면 이미지 + 버튼)
- [ ] **유니티 플레이 영상** - `IntroCutscene` 씬에서 작동하는 영상, **10~20초**
  - 장면을 넘기는 모습이 들어가야 합니다

### 제출 전 체크리스트

- [ ] 장면 이미지가 전부 **1920x1080**인가
- [ ] 파일명이 `cutscene01.png` 형식(접두사 + **두 자리** 번호)인가
- [ ] 버튼 3종이 214x87px인가
- [ ] **`Refresh Intro Cutscene Slides` 를 실행했는가**
- [ ] 첫 장면부터 마지막 장면까지 다 넘어가는가
- [ ] 마지막 장면 다음에 스테이지로 넘어가는가
- [ ] 건너뛰기가 작동하는가
- [ ] `Title` → 시작하기 → 인트로 → 스테이지 흐름이 끊기지 않는가
- [ ] Ctrl+S → Commit → **Push까지 완료**했는가
