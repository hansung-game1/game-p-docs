# 주차별 수업자료 (15주)

이 폴더는 **매주 진행하는 수업 단위**의 자료입니다. 상위 `ClassDocs` 폴더의 기본 문서(00~06)는 "전체를 한번에 설명하는 참고서"이고, 여기 있는 주차별 문서는 "이번 주에 무엇을 배우고 무엇을 해오는가"만 뽑아낸 실행 계획서입니다.

**읽는 순서**: 매주 수업 전에 그 주차 문서를 열고, 문서 안에서 링크로 걸린 기본 문서(00~06)의 해당 부분을 필요할 때만 펼쳐보면 됩니다.

## 이 수업의 큰 흐름

```
1주차          2~9주차                 10주차        11주차        12~14주차       15주차
환경 구축  →   러프(스케치) 제작   →   1차 빌드  →  모바일/사운드 → 완성·마감  →  발표
               (컬러링 없이 구조 완성)   ↑
                                    이 시점에 이미
                                   "돌아가는 게임"이
                                     완성되어 있음
```

**2~9주차는 전부 "러프 단계"입니다.** 컬러링을 하지 않고 스케치 상태로 작업하는 이유는, **먼저 게임 전체가 끝까지 돌아가게 만들어놓고 그 다음에 그림을 채우기 위해서**입니다. 실무에서도 같은 순서로 갑니다 - 그림을 완성해놓고 나중에 게임에 붙였다가 안 맞으면 그 완성도가 전부 낭비되기 때문입니다.

10주차에 처음 빌드를 만들어보면 "지금 무엇이 부족한지"가 눈에 보이고, 12~14주차에 그 부분을 집중해서 완성하는 구조입니다.

## 매주 공통 규칙

### 과제 제출

- 제출처: 네이버 카페
- 제목 형식: `2D게임제작_00주차_123456홍길동` (주차는 두 자리, 학번+이름 붙여쓰기)
- 마감: 다음 주 수업 전까지

### 문서는 교수님 저장소에서 보세요

**작업은 내 저장소에서, 문서는 교수님 저장소에서.**

내 저장소는 교수님 원본을 받아온 날짜에 멈춰 있는 사본이라, 그 안의 `ClassDocs`는 **시간이 지날수록 낡습니다.** 수업이 진행되면서 설명이 추가되고 잘못된 부분이 수정되므로, **문서는 항상 교수님 저장소에서** 보세요. (자세한 이유는 [01-② GitHub 계정](../기본설명/01_시작하기2_깃허브계정.md)의 "작업은 내 저장소에서, 문서는 교수님 저장소에서" 항목)

### 매주 작업이 끝나면

1. Unity에서 **Ctrl+S**로 씬 저장 (여러 씬을 만졌으면 각각 저장)
2. GitHub Desktop에서 **Commit → Push** ([01-③ GitHub Desktop](../기본설명/01_시작하기3_깃허브데스크탑.md) 참고)
3. 다른 컴퓨터(학교/집)에서 이어서 작업한다면, **시작하기 전에 반드시 `Pull` 먼저** ([01-③](../기본설명/01_시작하기3_깃허브데스크탑.md)의 5번 - 집 컴퓨터 최초 설정, 충돌 대처 포함)

### 절대 하지 말 것

- `Assets/_Project/01_Scripts` 등 코드 폴더 수정
- `04_Art/StudentReplace`와 `06_Audio` **바깥** 폴더의 파일 이름 변경/이동
- 메뉴 이름이 `Create ... Scene`으로 시작하는 도구 실행 (씬을 통째로 새로 만들어버림 - 자세한 건 [04_Unity_적용_가이드](../기본설명/04_Unity_적용_가이드.md) 참고)
