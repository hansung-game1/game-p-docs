# 7주차 - 타이틀 화면 · 메뉴 UI (러프 단계)

**이번 주 목표**: 게임을 켰을 때 처음 보이는 얼굴을 만든다.

---

## 1. 타이틀 화면의 특징 - 왜 중요한가

타이틀은 **플레이어가 이 게임에 대해 갖는 첫인상 전부**입니다. 게임 화면은 몇 초 만에 지나가지만, 타이틀은 플레이어가 가장 오래 들여다보는 정지 화면입니다.

또한 **평가와 발표에서 가장 먼저 눈에 들어오는 화면**이기도 합니다. 여러분의 게임을 대표하는 스크린샷이 될 가능성이 가장 높습니다.

### 타이틀 화면의 구성

```
┌────────────────────────────────────────────────┐
│  title_watermark.png  (학교/트랙 로고 - 고정)    │  ← 항상 맨 위, 학생이 수정 안 함
│                                                │
│         [ 게 임 로 고 · 타 이 틀 ]               │  ← title_background.png 안에 포함
│                                                │
│                                    ┌─────────┐ │
│      title_motion01~NN.png         │ 시작하기 │ │
│      (배경 위에서 반복 재생)         ├─────────┤ │
│                                    │ 조작설명 │ │
│                                    ├─────────┤ │
│                                    │  설정   │ │  ← 위치는 자유롭게 옮길 수 있음
│                                    ├─────────┤ │
│                                    │ 크레딧  │ │
│                                    ├─────────┤ │
│                                    │  종료   │ │
│                                    └─────────┘ │
│  title_background.png  (맨 뒤 정적 배경)        │
└────────────────────────────────────────────────┘
```

### 버튼을 누르면

| 버튼 | 결과 |
|---|---|
| **시작하기** | 인트로 컷신으로 → 게임 시작 |
| **조작설명** | `popup_controls.png` 팝업이 뜸 |
| **설정** | `popup_settings.png` 팝업 (BGM/효과음 볼륨 슬라이더 포함) |
| **크레딧** | `popup_credits.png` 팝업 |
| **종료** | 게임 종료 |

## 2. 리소스 제작 규격

폴더: `Assets/_Project/04_Art/StudentReplace/UI/Title/`

### 메인 버튼 5종 - 각 307 x 82px, 상태 3장씩

```
button_start_normal.png    / _hover.png / _click.png    시작하기
button_controls_normal.png / _hover.png / _click.png    조작설명
button_settings_normal.png / _hover.png / _click.png    설정
button_credits_normal.png  / _hover.png / _click.png    크레딧
button_quit_normal.png     / _hover.png / _click.png    종료
```

**총 15장.** 6주차 일시정지 메뉴 버튼과 **완전히 같은 규격(307x82)** 입니다 - 같은 디자인 시스템으로 만들면 통일성이 살고 작업량도 줄어듭니다.

![버튼 3상태와 307x82 규격 - 타이틀/일시정지/사망이 같은 버튼을 재사용](images/W06_ui_button_spec.svg)

### 팝업 배경 3종 - 각 602 x 715px

```
popup_controls.png   조작설명 팝업
popup_settings.png   설정 팝업
popup_credits.png    크레딧 팝업
```

> ★ **팝업 안의 안내 문구는 "그림 안에 텍스트로 직접 그려 넣습니다."** Unity가 글자를 따로 얹어주지 않습니다.
> - `popup_controls`: 조작키 안내를 직접 써넣으세요 (A/D 이동, Space 점프, Shift 대시, J 공격, K 필살기)
>
>   **여기까지가 플레이어가 쓰는 조작키 전부입니다.** `Ctrl+M`(즉사)·`Ctrl+L`(즉시 클리어)이나 `H`·`N`(피격 모션) 같은 **테스트용 키는 넣지 마세요** - 만드는 사람이 확인할 때 쓰는 것이지 플레이어가 알 필요가 없습니다. **굳이 넣고 싶다면 막지는 않습니다.** 본인 선택입니다.
> - `popup_credits`: 제작자(본인) 이름, 학번, 사용한 소스 출처 등
> - `popup_settings`: "BGM", "효과음" 같은 라벨. **슬라이더가 들어갈 자리는 비워두세요**

> ★ **`popup_controls.png` 와 `popup_settings.png` 는 일시정지 메뉴에서도 그대로 재사용됩니다.** 여기서 만들면 6주차의 일시정지 메뉴 팝업도 자동으로 같이 채워집니다. 반대로 말하면 **두 화면 어디에 놓아도 어울리는 디자인**이어야 합니다.

### 설정 팝업 부속

| 파일 | 크기 | 설명 |
|---|---|---|
| `button_settings_save.png` | **241 x 80px** | 저장 후 닫기 버튼 (**1장만** - 상태 이미지 없음, 정상입니다) |
| `slider_track.png` | **258 x 15px** | 슬라이더 홈 (BGM/효과음 **두 슬라이더가 공용**) |
| `slider_handle.png` | **18 x 53px** | 슬라이더 손잡이 (역시 공용) |

### 전체 화면 이미지 - 각 1920 x 1080px

| 파일 | 설명 |
|---|---|
| `title_background.png` | **가장 뒤에 깔리는 정적 배경. 게임 로고/타이틀 글자까지 포함해서 한 장으로 만듭니다** |
| `title_watermark.png` | 학교 로고 + 트랙 로고 + 하단 텍스트. **항상 최상단 고정 오버레이 - 학생이 수정하는 대상이 아닙니다** |

### 타이틀 배경 애니메이션 - 각 1920 x 1080px, 개수 자유

```
title_motion01.png, title_motion02.png, title_motion03.png ...
```

- `title_background.png` **바로 위**에서 반복 재생됩니다
- 버튼 클릭이나 팝업과 무관하게, 타이틀 화면에 있는 동안 **계속 반복**
- 번호는 **두 자리** (01, 02 ... 09, 10)
- 프레임 수는 자유롭게 늘리거나 줄여도 됩니다

> **무엇을 움직이면 좋은가**: 흔들리는 나뭇잎, 흐르는 구름, 깜빡이는 조명, 떨어지는 재, 캐릭터의 망토가 나부끼는 것 등. **전체를 다시 그릴 필요 없이, 움직이는 부분만 있는 투명 배경 그림**으로 만들면 작업이 훨씬 가볍습니다.
>
> 기본 재생 속도는 **5fps**(느긋한 느낌)입니다. `Hierarchy`의 `TitleMotion` 오브젝트 → `Title Background Motion Player` 컴포넌트 → `Frames Per Second` 값으로 조절할 수 있습니다.

### 공통 규칙

- PNG, **알파 채널 투명** (배경 바깥쪽은 투명)
- **파일명은 위에 적힌 그대로 정확히** (대소문자까지)
- **픽셀 크기 유지.** 달라졌으면 `Image` 컴포넌트의 **`Set Native Size`** 로 복구 (위치는 안 바뀝니다)
- **버튼의 화면상 위치는 자유** - Scene 뷰에서 원하는 자리로 옮겨도 됩니다 (그림과 클릭 영역이 같이 움직입니다)

### 러프 단계 작업 지침

- 컬러링 없이, 단 **디자인 컨셉은 담겨 있어야 함**
- **레이아웃(어디에 무엇이 놓이는가)을 확정하는 것**이 이번 주의 목표입니다
- **AI 사용을 허용합니다** - 배경 컨셉 시안, 아이디어 스케치 등에 활용해도 됩니다. 단, 최종적으로는 **본인 게임의 그림체와 통일되어야** 합니다

## 3. Unity에 적용하기

### 순서

**1) 그림을 `UI/Title` 폴더에 넣습니다.**

**2) 타이틀 씬을 엽니다.**

```
Assets/_Project/00_Scenes/Flow/Title.unity
```

**3) 반영합니다.**

- **파일명/개수를 그대로 두고 덮어쓴 경우**: 자동 반영됩니다. 아무것도 실행할 필요 없습니다
- **`title_motion` 프레임 개수를 바꾼 경우**:
  ```
  Tools > Class Template > Refresh Title Motion Frames
  ```

**4) 버튼 위치를 조정합니다** (원하는 경우).

`Hierarchy`에서 버튼을 선택 → Scene 뷰에서 드래그하거나 `Inspector`의 `Pos X` / `Pos Y` 조절.

**5) Ctrl+S로 저장**

> ⚠️ `Tools > Class Template > **Create Title Scene**` 은 **실행하지 마세요.** 타이틀 씬을 처음부터 다시 만들어서 지금까지 조정한 버튼 위치가 전부 사라집니다.

### 팝업을 편집 중에 확인하는 방법

팝업은 평소에 꺼져 있습니다. 위치와 크기를 Scene 뷰에서 보려면:

```
Tools > Class Template > Title Preview > 조작설명 팝업 토글
Tools > Class Template > Title Preview > 설정 팝업 토글
Tools > Class Template > Title Preview > 크레딧 팝업 토글
Tools > Class Template > Title Preview > 모두 닫기       ← 저장 전에 반드시
```

> ⚠️ **확인이 끝나면 반드시 `모두 닫기` → Ctrl+S** 순서로 저장하세요. 팝업을 켜둔 채 저장하면 Play를 시작하자마자 팝업이 떠 있는 채로 시작합니다.

슬라이더 손잡이를 편집 중에 잘못 움직였다면:
```
Tools > Class Template > Title Preview > 슬라이더 손잡이 원래대로
```

### 타이틀 BGM (선택, 11주차에 본격적으로 다룸)

`Assets/_Project/06_Audio/BGM/Title/` 폴더에 음원 파일 하나를 넣고:

```
Tools > Class Template > Add Background Music To Title Scene
```

## 4. 확인하고 수정하기

`Title` 씬에서 Play.

| 확인 항목 | 방법 |
|---|---|
| 배경과 로고가 정상으로 보이나 | Play 직후 화면 |
| **배경 애니메이션이 반복 재생되나** | 몇 초 지켜보기 |
| 재생 속도가 적당한가 | 너무 빠르면 `Frames Per Second` 낮추기 |
| 버튼 5개가 다 보이나 | |
| **마우스를 올리면 hover 그림으로 바뀌나** | 버튼마다 올려보기 |
| 누르면 click 그림으로 바뀌나 | |
| 조작설명 / 설정 / 크레딧 팝업이 뜨나 | 각각 클릭 |
| **팝업 안 글씨가 읽히나** | 화면에서 실제 크기로 확인 |
| 설정 슬라이더가 움직이나 | 드래그해보기 |
| **시작하기를 누르면 인트로 컷신으로 넘어가나** | |
| 워터마크가 맨 위에 정상으로 보이나 | |

### 잘 안 될 때

| 증상 | 원인 |
|---|---|
| 그림이 안 바뀜 | 파일명 오타 (`button_start_normal.png` 처럼 정확히) |
| 버튼이 찌그러짐 | 크기가 307x82가 아님 → `Image` → **`Set Native Size`** |
| 마우스를 올려도 안 바뀜 | `_hover` / `_click` 파일이 없거나 이름이 틀림 |
| 배경 애니메이션이 안 나옴 | 파일명이 `title_motion01.png` 형식인지 확인 + `Refresh Title Motion Frames` 실행 |
| 프레임을 늘렸는데 반영이 안 됨 | `Refresh Title Motion Frames` 미실행 |
| **Play하자마자 팝업이 떠 있음** | Title Preview를 켠 채 저장했음 → `모두 닫기` → Ctrl+S |
| 팝업 글씨가 안 읽힘 | 602x715 안에 글씨를 너무 작게 그렸음. 실제 화면에서는 이보다 더 작게 보입니다 |
| 슬라이더 손잡이가 엉뚱한 곳에 | `Title Preview > 슬라이더 손잡이 원래대로` |
| 일시정지 메뉴의 팝업도 같이 바뀜 | **정상입니다** (의도된 재사용) |

## 과제 (7주차)

### 무엇을 해오나

**타이틀 화면과 메뉴 UI를 러프(스케치) 상태로 제작하고 Unity에 적용하기**

- 완성본이 아닌 **스케치 버전의 러프** 상태
- 스케치지만 **디자인 컨셉은 담겨 있어야 함** (컬러링 X)
- **AI 사용을 허용합니다**

### 제출

네이버 카페 업로드 - 제목 `2D게임제작_07주차_123456김한성`

- [ ] **타이틀 화면 / 메뉴 UI 리소스**
- [ ] **유니티 플레이 영상** - `Title` 씬에서 작동하는 영상, **10~20초**
  - 배경 애니메이션이 반복되는 모습 + 버튼 hover + 팝업 여닫기가 들어가면 좋습니다

### 제출 전 체크리스트

- [ ] 버튼 5종 × 3상태 = **15장**이 전부 307x82px인가
- [ ] 팝업 3종이 602x715px이고, **안내 문구가 그림 안에 들어가 있는가**
- [ ] `title_background.png`가 1920x1080이고 **게임 로고가 포함**되어 있는가
- [ ] `title_motion01.png` 부터 두 자리 번호로 순서대로 되어 있는가
- [ ] 프레임 개수를 바꿨다면 `Refresh Title Motion Frames` 를 실행했는가
- [ ] **Title Preview 팝업을 전부 닫고 저장했는가**
- [ ] 시작하기 → 인트로 컷신으로 실제로 넘어가는가
- [ ] Ctrl+S → Commit → **Push까지 완료**했는가
