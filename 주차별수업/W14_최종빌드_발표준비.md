# 14주차 - 리소스 완성 3 · 최종 빌드 · 발표 준비 (졸업전시 주간)

**이번 주 목표**: 마감하고, **최종 빌드를 만들고, 최종 제출물을 전부 만든다.**

> ⚠️ **이번 주가 실질적인 마감입니다.** 15주차는 발표만 진행합니다. 졸업전시 주간과 겹치므로 **시간 배분에 특히 주의하세요.**

---

## 1. 이번 주 진행 순서

```
① 마감 점검 (부족한 부분 보완)
      ↓
② 전체 흐름 최종 확인
      ↓
③ 최종 빌드 (PC + 모바일)
      ↓
④ 전체 플레이 영상 녹화 (1~2분 내외)
      ↓
⑤ 종합결과 보고 PPT 작성
      ↓
⑥ 제출 (15주차 수업 전까지)
```

**③ 빌드부터는 시간이 오래 걸립니다.** 마감 작업을 무한정 끌지 말고, **빌드 시작 시각을 미리 정해두세요.**

완성도를 더 올리기 전에, **비어 있는 곳이 없는지** 먼저 확인하세요. 못 그린 것보다 **아예 빠진 것**이 감점이 큽니다.

| 항목 | 확인 |
|---|---|
| 플레이어 12개 동작 전부 | [ ] |
| 몬스터 A(5) / B(8) / C(7+투사체) 전부 | [ ] |
| 플레이어 이펙트 6종 | [ ] |
| 바닥 `ground1~7` / 배경 `bg1~5` | [ ] |
| HUD 5개 파일 | [ ] |

| 시작/클리어 배너, 클리어 오브젝트 | [ ] |

> **임시 그림이 남아 있는 곳을 찾는 법**: `Title` 씬부터 엔딩까지 플레이하면서 화면을 천천히 훑어보세요. 아직 안 채운 자리는 밋밋한 색 블록으로 나옵니다.

### 아직 시간이 남는다면 - 완성도 올리기

- 가장 오래 보이는 것부터: **플레이어 idle/walk/attack**, **배경**, **타이틀**
- 전체 톤 통일 (13주차 "대표 화면 6장" 비교법)
- HP 아이템 박스, 날씨 효과 등 아직 안 넣은 선택 요소

## 3. 전체 흐름 최종 확인 (빌드 전 필수)

**에디터에서** `Title` 씬을 열고 Play → 끝까지.

- [ ] 타이틀 → 인트로 → 스테이지 → 클리어 → 엔딩 → 타이틀 복귀
- [ ] 죽었을 때 사망 화면 → 재도전 / 타이틀로가 정상
- [ ] 일시정지 메뉴 6개 버튼 전부 동작
- [ ] 조작설명 / 설정 / 크레딧 팝업이 뜨고 닫힘
- [ ] 설정 슬라이더로 볼륨이 실제로 바뀜
- [ ] BGM과 효과음이 다 들림
- [ ] **Play 시작 시 메뉴나 클리어 화면이 떠 있지 않음** (Preview 토글 확인)
- [ ] **Console에 빨간 에러(Error)가 없음** ← 에러가 있으면 빌드가 실패합니다
- [ ] 모든 씬 **Ctrl+S** 저장 완료

### Build Settings 확인

`File > Build Settings` → **Scenes In Build**:

- [ ] `Title` ← **0번(맨 위)**
- [ ] `IntroCutscene`
- [ ] `BackgroundTest`
- [ ] `EndingCutscene`
- [ ] 테스트 씬(`ActionTest`, `MonsterA/B/C_ActionTest`)은 **체크 해제**

> 자세한 개념은 [W10_1차_빌드](W10_1차_빌드.md)의 "Build Settings 씬 목록" 항목을 다시 보세요.

## 4. 최종 빌드 만들기

### PC (Windows)

1. `File > Build Settings` → Platform **`Windows, Mac, Linux`** → `Switch Platform`
2. **`Build`** 클릭 (`Build And Run` 아님)
3. 저장 위치: `Assets/_Project/10_Builds/Windows/` 안에 새 폴더
4. 빌드 완료 후 **`.exe`를 직접 실행해서 처음부터 끝까지 확인**
5. ★ **폴더 전체를 압축** - `.exe`만이 아니라 `_Data` 폴더, `.dll`, `MonoBleedingEdge` 전부 포함

```
압축 파일명: PC_최종빌드_123456김한성
```

### 모바일 (Android)

1. `File > Build Settings` → Platform **`Android`** → `Switch Platform`
   - ⏰ 전환에 **10~40분** 소요
2. `Build` → 저장 위치와 파일명 지정
3. 빌드 완료 (**20~60분**)
4. **실제 안드로이드 기기에 설치해서 확인**
   - 터치 컨트롤이 나오는지, 조작이 되는지, UI가 잘리지 않는지

```
압축 파일명: M_최종빌드_123456김한성
```

> ⏰ **PC + 모바일 빌드에 총 1~2시간이 걸릴 수 있습니다.** 마감 직전에 시작하지 마세요. 빌드 도중에는 다른 작업(PPT 작성 등)을 하면 됩니다.

### 빌드가 실패하면

| 증상 | 확인 |
|---|---|
| `Build` 버튼이 회색 | 씬을 저장하지 않았거나 Console에 에러가 있음 |
| 빌드 도중 에러 | Console 전체 로그를 캡처해서 질문 |
| Android SDK/NDK 에러 | [W10_1차_빌드](W10_1차_빌드.md)의 "자주 나오는 에러" 표 참고 |
| `.exe`는 됐는데 실행하면 검은 화면 | Build Settings 0번 씬이 `Title`인지 확인 |

## 5. 전체 플레이 영상 녹화 (1~2분 내외)

### 무엇을 담나

**빌드된 실행 파일**을 녹화합니다 (에디터 화면 아님).

짧은 시간에 게임 전체를 보여줘야 하므로 **구성을 미리 정하고 찍으세요.** 아래는 **1분짜리 예시**입니다 - 2분까지 늘려도 됩니다.

| 시간 | 내용 |
|---|---|
| 0:00~0:10 | 타이틀 화면 (배경 애니메이션이 보이게) |
| 0:10~0:20 | 인트로 컷신 (넘기며) |
| 0:20~0:45 | **스테이지 전투** - 몬스터 A·B·C와 싸우는 장면, 필살기 |
| 0:45~0:55 | 클리어 → 엔딩 컷신 |
| 0:55~1:00 | 엔딩 마지막 장면 |

### 녹화 요령

- **OBS Studio**(무료) 또는 Windows 게임 바(`Win + G`)
- ★ **소리가 녹음되도록 설정** - 녹화 후 반드시 재생해서 소리를 확인하세요
- 1920x1080, 30fps 이상
- 편집이 가능하면 지루한 이동 구간은 잘라내세요

## 6. 종합결과 보고 PPT

### 구성 (권장)

| 슬라이드 | 내용 |
|---|---|
| **1. 표지** | 게임 제목 + **대표 이미지** (타이틀 화면 또는 엔딩 일러스트) + 학번·이름 |
| **2. 게임 소개** | 한 줄 컨셉, 세계관, 장르 |
| **3. 컨셉 / 기획 의도** | 어떤 분위기를 목표로 했는지, 참고한 것 |
| **4. 캐릭터** | 주인공 컨셉 + 동작 스프라이트 시트 |
| **5. 몬스터** | 3종 소개 + 각각의 디자인 의도 |
| **6. 배경 / 스테이지** | **패럴렉스 5겹을 분해해서 보여주기** (효과적입니다) |
| **7. UI / 컷신** | 타이틀, 메뉴, 컷신 |
| **8. 작업 과정** | ★ **러프 → 완성 비교 이미지** (가장 반응이 좋은 슬라이드입니다) |
| **9. 게임 플레이 화면** | 대표 스크린샷 (13주차의 6장) |
| **10. 소감 / 배운 점** | 어려웠던 점, 해결 과정, 앞으로 |

### 작성 요령

- **글보다 이미지 위주로.** 발표는 말로 하고, 슬라이드는 보여주는 역할입니다
- **러프 → 완성 비교**를 꼭 넣으세요. 15주 동안의 작업량이 한눈에 보입니다
- 패럴렉스 레이어 분해 이미지는 **"게임 그래픽을 이해했다"** 는 것을 가장 잘 보여줍니다
- 소감은 형식적으로 쓰지 말고, **실제로 막혔던 지점과 어떻게 풀었는지**를 쓰세요. 그게 진짜 경험입니다

## 최종 제출 전 체크리스트

### 게임

- [ ] 타이틀 → 인트로 → 스테이지 → 클리어 → 엔딩 → 타이틀 흐름이 끊기지 않는가
- [ ] 사망 → 재도전이 정상인가
- [ ] 임시 그림(단색 블록)이 남아 있는 곳이 없는가
- [ ] 캐릭터/몬스터 애니메이션이 전부 정상 재생되는가
- [ ] **공격 판정이 정상인가** (판정 프레임 문제 없는지)
- [ ] 그림이 깨지거나(투명이 흰색으로) 잘려 보이지 않는가
- [ ] HP·게이지·일시정지 메뉴가 정상 동작하는가
- [ ] BGM/효과음이 다 들리는가
- [ ] 크레딧 팝업에 본인 정보와 출처가 적혀 있는가

### 빌드

- [ ] PC `.exe`가 **에디터 없이** 실행되는가
- [ ] PC 압축 파일에 **폴더 전체**가 들어 있는가 (`_Data`, `.dll` 포함)
- [ ] `.apk`가 실제 기기에 설치·실행되는가
- [ ] 모바일에서 터치 컨트롤이 나오고 조작이 되는가
- [ ] 압축 파일명이 규칙과 정확히 일치하는가

### 제출물

- [ ] PPT에 러프 → 완성 비교가 들어 있는가
- [ ] 플레이 영상에 **소리가 들어 있는가**
- [ ] 플레이 영상이 **빌드 파일**을 녹화한 것인가
- [ ] 구글 드라이브 링크의 다운로드 권한을 **로그아웃 상태로** 확인했는가
- [ ] GitHub 저장소에 최종본이 **Push**되어 있는가
